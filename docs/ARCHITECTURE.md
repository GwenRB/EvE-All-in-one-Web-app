# Architecture

Everything is in `EVE Industry Management.html`: `<style>` (theme tokens on `:root`, light/dark), the page markup (one `<div id="page-…" class="page">` per page), then one `<script>`.

## State and storage
- `state` (global): `chars` (skills, ESI data per character: jobs, planets, wallet, clones, fatigue, `loc`, `ship`, `queue` (`{at, list: [{n, l, start, end}]}` in training order), `calendar` (`{at, list: [{id, at, title, imp, resp, dur, owner, text}]}`, `fetchCalendar`; shown by `renderFleets` / `fleetEvents`), `lp` (`{at, list: [[corporation, points]]}`)…), `misc` (most feature settings), `forecast`, `fits`, `assets`, `contracts`, `typeNames` / `typeMeta` / `locNames` caches, `roles`…
- localStorage keys (all `eve-industry-*`): `roster` (characters), `misc`, `forecast`, `fits`, `assets`, `contracts`, `jita` (Jita price cache), `esi-tokens`, `esi-client`, `scopes-on/-off/-seen`, `notes`, `roles`, `ships`, `bp-*`, `cal-colors`, `corp-*`, `news` (news cache per channel, `{ v: 2, ch: { id: { at, url, title, items } } }`)…
- IndexedDB (`idb.get/set`): the map data, the wallet history (`pnl`, also in backups), moon mining (`mining`) and notifications (`intel`) (90 days, not in backups), Build planning snapshots of orders (`order:<id>`), CCP's game data index (`ccp:meta`, `ccp:p0`…`ccp:p63`; not in backups, rebuilt from CCP's site).
- `state.misc` namespaces worth knowing: `build` (Build planning settings, via `buildCfg()`; `build.ore` = ore options and `places`, the reprocessing places), `rxn` (+ `rxnData` formulas from the static data), `pi` (+ `piSchem` recipes, `piHist`, `piVol`), `pricings` (custom pricings), `orders`, `sc` (supply chain, `v` 2: max wait, focus cost/time, `horizon` days, `done` moves, `seen` = what the hangars held when a move was first planned, `ships` = per-ship use/type/position, `added` = ships added by hand, `freight` trips no ship can do; `pilots` = the older per-pilot settings, migrated), `news` (EvE News channels, in order), `corp` (Corporation page: fuel pricing/block/warning, mining period/value), `intel` (`days`, `seen`), `tz` (the Overview's time zones after EVE time), `doctrine`, `structs` / `indy` / `friendly` (structures), `rigData` (v2: manufacturing/reaction rigs in `list`, laboratory rigs in `sci`), `types` (ship data), `map`, `hiddenTabs`.

## Shared systems (reuse them)
- **Pricing** (Settings → Pricings): base modes `jbv`, `split`, `jsv` (Jita 4-4 from ESI orders, `jitaFetch` → `jitaCache[t] = {p: sell, b: buy}`) plus custom pricings `p:<id>`: a % of another pricing, or a citadel's market (`kind: "cit"`, `sid`, `side`). Use `priceIn(id, t)` (sync, null when unknown), `pricesIn(ids, id)` / `ensurePrices` (async), `pricingOptions(cur, attrs)` for selects, `validPricing`, `pricingName`. A citadel that can't be read is recorded in `citErr`. Show missing prices with `noPriceNote(pricingId, items, what)`.
- **Structures and rigs:** `STRUCTS` (role bonuses), `rigBonus(st, "me"|"te", recipe, isReaction, sec)` with real rig data from EVE Ref (security multipliers hi/lo/null), `sciBonus(st, "inv"|"copy", sec)` for laboratory rigs.
- **Systems:** `industrySystem(name)` → `{id, name, sec, idx}` (cost indices from ESI), `mapIndex()` → `{byId, byName}` of map systems (`s.n` name, `s.s` security, `x/y/z`).
- **Hauling:** jump freighters / Rorquals (`JFS`, `haulCapacity`, `jumpFuel`, `isoPrice`) or a freight service (ISK/m³ + collateral). `computeHaul(resStub)` prices round trips from a delivery system (used by Reactions, PI and Build planning). Routes: `jumpAnchor` + `gatePath` for high-sec ends, `findJumpRoute(from, to, range, jumpable)` (note: O(systems²), memoize).
- **Static data:** `sdeBuild()` reads the current build number; `sdeZip(build)` downloads the static data zip (about 100 MB) once per session (shared by the game data index, the map, Reactions and PI); `zipLines(entry, onLine)` streams a `.jsonl` file out of it.
- **Game data lookups:** `getJSON(REF + "/types/<id>")` (also `/blueprints/`, `/groups/`, `/categories/`, `/market_groups/`, `/schematics/`) returns EVE Ref's shape, built from CCP's index (`src: "ccp"`); the index is checked against CCP's build once a day, and when CCP's site can't be reached the stored copy is used (or EVE Ref for 10 minutes). A small status at the bottom left shows while the index is being built (first time: download + about 15 s). When several blueprints make an item (CCP keeps unpublished test ones), use `bpSource(type, activity)`.
- **ESI market reads:** always through `esiMarket(url, init)` (one queue for every page: at most 6 at once, under 90% of ESI's market budget of about 12,000 requests per 15 minutes per IP, ESI's `X-Ratelimit-*` / error-limit headers followed, a 429/420 pauses every read for its Retry-After, the visible page first; status `#mkt-status`). After the last try it answers with ESI's refusal.
- **Jita prices:** `jitaFetch(ids)` reads ESI market orders (Jita 4-4 sell/buy) through `esiMarket`, 3 items at a time: a refused read keeps the last price and is retried after ~2 minutes (never stored as "nobody sells it").
- **Formatting:** `isk`, `iskFull`, `fmtDur(seconds)`, `fmtDate(ms)`, `ago(ms)`, `icon(typeId)`, `iconBp`.
- **Tables, groups, panels, rails:** see `shared UI` above; saved in `state.misc.sorts` (`t:<key>` = `{col, dir}`), `state.misc.folds`, `state.misc.panels`. Page notes: `HOWTO[page]` → the folded footer (`renderHowto`).
- **Copy buttons:** any element with `data-copy="text"` (+ `data-copy-msg`) copies on click; classes `cargo` / `copyname` style them.

## External services
- ESI `https://esi.evetech.net` (public + authenticated, `esiGet`, `esiAuthGet` (a path may carry its own query, e.g. `?from_id=`), `fetchRetry`), SSO `login.eveonline.com`.
- CCP static data `https://developers.eveonline.com/static-data/…` (via `/proxy` when CORS blocks): game data index, map, reaction formulas, planet schematics.
- EVE launcher news `https://launcher.eveonline.com/resources/eve-online/news_v4/en.json` and other news channels (RSS/Atom/JSON feeds), all via `/proxy`.
- EVE Ref `https://ref-data.everef.net`: fallback only (game data lookups, map, reaction formulas).
- Images `images.evetech.net`; overview bracket icons from the EVE University wiki.
