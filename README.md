# EVE Industry Management

A local tool for running EVE Online industry across several characters: skills, jobs, assets, prices, build planning, reactions, PI, orders, doctrines and jump freighter logistics.

## Use it
1. Keep `EVE Industry Management.html` and the launcher in the same folder.
2. Start `start-eve-industry-management.sh` (macOS/Linux, needs Python 3) or `Start EVE Industry Management.bat` (Windows).
3. Open http://localhost:8642/ (the launcher opens it for you). Link characters through ESI from the top of the page.

Your data stays in your browser; use Settings → Export backup to move it.
